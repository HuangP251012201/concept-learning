# 概念学习资料生成器（Concept Learning Material Generator）

把"学习一个新概念"这件重复性工作流程化：给定任意概念，产出一份结构一致、可复习、可核查、带个人理解的学习资料。它不是一个为某几个概念写死的一次性提示词，而是一套可复用的生成规范。

## 1. 适用场景

- 你想系统学习一个**新的技术/学术概念**（例如：Agent、上下文、Skill、RAG、注意力机制、向量数据库……），希望一次拿到一份完整、可复习的资料。
- 你在准备课程作业、技术面试或写作学习笔记，需要一个**稳定模板**，保证多份资料结构统一、质量可控。
- 你想把"学习新概念"这件事**流程化、批量化**，避免每次从零组织。

> 本 Skill 与具体概念解耦：换一个概念名即可复用，不需要改写流程。

## 2. 输入信息

调用时至少提供：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `概念名称` | 必填 | 要学习的概念，中英文均可 |
| `所属领域` | 可选 | 如"AI Agent""大模型""软件工程" |
| `目标读者` | 可选 | 默认"有一定编程基础的学习者" |
| `已有资料/链接` | 可选 | 用户手头的一手材料，优先采用 |

## 3. 生成步骤

1. **界定概念边界**：先用自己的话给概念下定义，再查找权威资料校正，避免望文生义。
2. **拆解核心机制/组成**：把概念拆成 3–5 个可理解的组成部分或运行机制。
3. **找一个具体应用场景**：选一个真实、可复述的案例，说明该概念如何被使用。
4. **辨析易混淆点与边界**：找出 2–3 个容易与它混淆、或使用中容易踩坑的地方。
5. **设计自测问题**：出 2–3 个能检验"是否真的理解"（而非死记硬背）的问题。
6. **收集可核查来源**：为关键论断标注官方文档 / 权威博客 / 论文链接，**不得伪造**。
7. **按下方结构生成输出**（HTML 或 Markdown）。

## 4. 输出结构

每份学习资料必须包含以下七个部分（顺序可微调，但不可缺项）：

1. **一句话定义**
2. **个人解释**：用自己的话，禁止整段照抄 AI 原文
3. **核心机制或组成**
4. **一个具体应用场景**
5. **易混淆点 / 使用边界**
6. **自测问题**
7. **可核查的资料来源**（附真实链接）

## 5. 资料来源要求

- 优先使用**官方文档、一手论文、厂商官方 engineering blog**。
- 每个关键论断都要能回溯到具体来源；**链接必须真实有效**，不确定的链接先用搜索核实。
- **严禁编造来源**；宁可少列，不可列假。

## 6. 自检要求（生成后必查）

- [ ] 定义是否准确、无歧义？
- [ ] "个人解释"是否真的是"用自己的话"，而非照搬原文？
- [ ] 核心机制是否拆解清晰、无遗漏关键维度？
- [ ] 应用场景是否具体、可复述？
- [ ] 每条来源链接是否可打开、内容是否支撑对应论断？
- [ ] 输出是否适合目标读者阅读？

## 7. 示例

本仓库 `learning-materials/` 目录下的 `agent.html`、`llm-context.html`、`skill.html` 三份资料，就是按本 Skill 生成的成品示例，可作为输出范本参考。
